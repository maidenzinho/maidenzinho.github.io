Adicione quantos simulados quiser enviando arquivos HTML ou JSON. Eles aparecerão na biblioteca deste navegador.

📤

Arraste arquivos HTML para cá

Ou clique para escolher um ou mais arquivos do computador.

Aceita .html, .htm e .json

✨ Formatos compatíveis

HTML de questões com lista const DATA = [...]; HTML com <script id="quiz-data" type="application/json">; e JSON com perguntas/alternativas/gabaritos.

Se o HTML possuir outro sistema de questões, ele abrirá no visualizador de HTML original, sem executar scripts com acesso aos dados deste portal.

💾 Onde os arquivos ficam?

Os arquivos importados são mantidos no armazenamento local do navegador (IndexedDB). Não são enviados automaticamente ao GitHub nem compartilhados com outros aparelhos.

As importações ficam neste navegador. Para disponibilizar uma prova em todos os dispositivos, publique o HTML e registre-o em catalogo.json no GitHub Pages.
